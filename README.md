# Geopolitical Capital Club

Website for the Geopolitical Capital Club (GCC), a student organization focused on how global events shape businesses and new ventures.

GCC has two connected tracks:
- **Analyst:** Research, financial modeling, and business evaluation.
- **Studio:** Developing and testing startup ideas, with feedback from analyst teams at key milestones.

The site introduces the program, explains membership, and presents the club’s leadership.

## Development

Built with React, TypeScript, and Vite.
